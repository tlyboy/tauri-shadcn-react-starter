# tauri-shadcn-react-starter

🚀 Tauri shadcn react starter

## Install

```bash
npx degit tlyboy/tauri-shadcn-react-starter my-project
```

## Usage

Requires [Rust](https://www.rust-lang.org/) to be installed.

```bash
pnpm install
pnpm tauri dev
pnpm tauri build
```
