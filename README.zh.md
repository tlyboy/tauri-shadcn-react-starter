# tauri-shadcn-react-starter

🚀 Tauri shadcn react starter

## 安装

```bash
npx degit tlyboy/tauri-shadcn-react-starter my-project
```

## 使用说明

需要安装 [Rust](https://www.rust-lang.org/)。

```bash
pnpm install
pnpm tauri dev
pnpm tauri build
```
